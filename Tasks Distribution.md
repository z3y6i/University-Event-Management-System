## Assigned Use Cases
**Register for Event :** This use case allows a student to register for a university event. The student selects an available event, views its details, and submits a registration request to participate.



**Create Event :** This use case allows an event organizer to create a new event by providing details such as the event name, date, location, description, and participant capacity.



**Search Event :** This use case enables students to search for events using keywords, categories, or dates. It helps users quickly find events that match their interests.



**Cancel Registration :** This use case allows a student to cancel a previously completed event registration. The system updates the participant list and frees the reserved seat for other students.
