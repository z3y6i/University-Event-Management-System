## Project Overview
The University Event Management System is a software application designed to help universities manage campus events efficiently. The system allows students to browse and register for events, event organizers to create and manage events, and administrators to supervise the overall event process.
Students can search for events, view event details, register for events, cancel registrations, and provide feedback. Event organizers can create, edit, and cancel events, as well as manage attendance and view participant information. Administrators can manage users, approve or reject event requests, monitor events, and generate reports.
The main objective of the system is to simplify event management, improve communication between students and organizers, and provide an organized platform for handling university activities.
